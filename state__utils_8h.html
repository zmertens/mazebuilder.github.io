inlinenoexcept

Resets the grid's topology (links) before each generation.

resize() always clears cell links even when dimensions are unchanged; without this, repeated maze generation at the same size (e.g. rebuilding on keypress) would keep linking new random walls on top of the previous maze's links, so the maze gradually loses walls / becomes fully open over time.

rowsDesired number of rows.
