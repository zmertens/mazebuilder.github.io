Detailed Description

Base state for creating output from mazes (pixels, stringify, OBJ) This state encapsulates the common setup, creation, and output-writing logic for states that generate maze output in various formats. The output argument is either a file path (the extension selects the format) or a bare keyword that prints to stdout: "stdout" (plain string), "obj" (Wavefront OBJ), "b64" (base64-encoded string).
